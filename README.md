# Frontend Development Assessment

A frontend development project in which I am tasked to fetche geographic statistical data from a public source, present it through both visual charts and data tables, and show interconnected functionality between those components.

The dependencies I used are: sass for styling, axios to make HTTP requests, cors to permit my app to access resources from a different domain, papaparse for parsing CSV data, react-dom to render into the browser’s DOM, react-router-dom to make my app an SPA, and recharts to plot data parsed from the CSV file.

This project consists of the two major components, as follows:

## Loading and Parsing CSV Data from API into Data Table
Used axios to make HTTP requests and papaparse for parsing CSV data

## Plotting Data on Scatter Plot
Used recharts to plot data parsed from the CSV file

## To Run
You may clone from the develop branch, and run in development (npm run dev)
